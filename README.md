# E foi assim...

Plataforma para criar aventuras para o TT RPG educacional "E foi assim...".

O PDF do sistema pode ser encontrado em:
<a href="https://drive.google.com/drive/folders/1rPDQilEKIL6Qlj18pJ0lHbknNIrcucBS"> Pasta do sistema no Google Drive </a>.

<p>Como a gente sabe que a gravidade que nos puxa para baixo é a mesma que mantém a Lua perto da Terra? Como a gente sabe que nosso código genético está numa molécula helicoidal dentro de cada célula? Como a gente sabe que a matéria é composta de átomos que são compostos por partículas ainda menores? Como a gente sabe que, entre tantos órgãos, é no cérebro que os pensamentos acontecem?<p>
<p>Foi assim… Você, jogador, não é o protagonista, é apenas uma engrenagem de um sistema que precisa funcionar novamente da mesma forma que antes para fazer com que o conhecimento seja adquirido e, com isso, impedir o caos no futuro.<p>
<p>Seu objetivo? Garantir que uma descoberta aconteça. Seu desafio? A história não pode saber que você esteve aqui. O reconhecimento será todo do cientista, mas o jogo... o jogo é todo seu.<p>

## Como usar

<p>Na opção "<b>Nova Ficha</b>", você cria uma ficha de aventura do zero. Ao terminar de preencher os campos, você tem a opção de baixar a ficha em JSON (formato estruturado que pode ser reaberto e editado), SVG (formato de imagem) ou visualizar o HTML, no qual pode imprimir ou gerar o PDF. Ao escolher qualquer uma dessas opções, a ficha será salva online e ficará disponível para outras pessoas.<p>
<p>Na opção "<b>Carregar Ficha</b>", você pode reabrir uma ficha feita anteriormente e baixada no formato JSON. Então poderá continuar a editá-la.<p>
<p>Na opção "<b>Pesquisar Ficha</b>", poderá pesquisar entre as fichas criadas por todos os usuários. Utilizando vários filtros. Tenho certeza de que encontrará muitas aventuras interessantes<p>
